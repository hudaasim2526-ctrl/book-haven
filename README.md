# 📚 Heaven — Bookstore Website

**Heaven** is a modern and responsive bookstore website UI designed to create a clean, elegant, and user-friendly online book browsing experience. The website focuses on a visually appealing layout, organized book sections, and a smooth responsive design across different screen sizes.

## ✨ Features

* 📖 Clean and modern bookstore UI
* 📱 Fully responsive layout
* 🧭 Simple and user-friendly navigation
* 📚 Organized book collection sections
* 🔍 Attractive book/product presentation
* 🎨 Clean typography and visual design
* 🖥️ Desktop, tablet, and mobile-friendly layout
* ⚡ Lightweight frontend implementation

## 🛠️ Technologies Used

* **HTML5** — Website structure and content
* **CSS3** — Styling, layout, responsiveness, and visual design

## 📌 Website Sections

The website includes different sections designed to present the bookstore content in an organized way, including:

* Home / Hero Section
* Book Collection
* Featured Books
* About Section
* Contact / Footer Section

## 🎯 Project Purpose

This project was created as a **frontend web development practice project** to improve skills in HTML, CSS, responsive layouts, website structure, and modern UI design.

## 💻 What I Practiced

* Creating structured webpages with HTML5
* Designing responsive layouts with CSS3
* Using Flexbox and Grid for page layouts
* Creating reusable UI sections
* Improving spacing, typography, and visual hierarchy
* Making websites responsive for different screen sizes
